# Git Bash Commands

A collection of **Git Bash commands and practice examples** covering fundamental and commonly used Git operations for version control and repository management.

This repository is focused specifically on **Git commands executed using Git Bash** for repository management, file tracking, branching, merging, remote repository operations, and version control.

## 📚 Topics Covered

### Git Configuration and Repository Setup

- Checking Git Version (`git --version`)
- Configuring Git Username (`git config user.name`)
- Configuring Git Email (`git config user.email`)
- Viewing Git Configuration (`git config --list`)
- Initializing a Git Repository (`git init`)
- Cloning a Remote Repository (`git clone`)

### Git File Tracking and Commit Operations

- Checking Repository Status (`git status`)
- Adding Files to Staging Area (`git add`)
- Removing Files from Staging Area (`git restore --staged`)
- Committing Changes (`git commit`)
- Viewing Commit History (`git log`)
- Viewing Commit Details (`git show`)
- Comparing File Changes (`git diff`)
- Restoring File Changes (`git restore`)
- Removing Tracked Files (`git rm`)
- Renaming and Moving Files (`git mv`)

### Git Branch Management

- Creating Branches (`git branch`)
- Listing Local Branches (`git branch -l`)
- Listing Remote Branches (`git branch -r`)
- Listing All Branches (`git branch -a`)
- Switching Between Branches (`git switch`, `git checkout`)
- Creating and Switching to a New Branch (`git switch -c`)
- Renaming Branches (`git branch -m`)
- Deleting Local Branches (`git branch -d`, `git branch -D`)
- Merging Branches (`git merge`)
- Comparing Branches (`git diff`)

### Git Remote Repository Operations

- Viewing Remote Repositories (`git remote -v`)
- Adding a Remote Repository (`git remote add`)
- Removing a Remote Repository (`git remote remove`)
- Fetching Changes from Remote (`git fetch`)
- Pulling Changes from Remote (`git pull`)
- Pushing Changes to Remote (`git push`)
- Setting Upstream Branch (`git push -u`)
- Viewing Remote Repository Information (`git remote show`)

### Git History and Undo Operations

- Viewing Commit History (`git log`)
- Viewing Changes in Commits (`git show`)
- Reverting Commits (`git revert`)
- Resetting Commits (`git reset`)
- Amending the Last Commit (`git commit --amend`)
- Viewing Reference History (`git reflog`)
- Comparing Commits (`git diff`)
- Viewing File History (`git log --follow`)

### Git Stashing and Tagging

- Saving Uncommitted Changes (`git stash`)
- Listing Saved Stashes (`git stash list`)
- Applying Stashed Changes (`git stash apply`)
- Restoring and Removing a Stash (`git stash pop`)
- Deleting Stashes (`git stash drop`)
- Creating Tags (`git tag`)
- Listing Tags (`git tag -l`)
- Pushing Tags to Remote (`git push --tags`)

## 🎯 Purpose

This repository is created for:

- Learning and practicing Git commands using Git Bash
- Understanding Git version control concepts and workflows
- Gaining hands-on experience with Git repositories
- Practicing file staging, committing, and tracking changes
- Understanding Git branching, merging, and branch management
- Working with local and remote GitHub repositories
- Practicing Git push, pull, fetch, and clone operations
- Understanding commit history, reverting changes, and resolving conflicts
- Improving Git troubleshooting and repository management skills
- Preparing for Git, GitHub, and software development-related interviews
